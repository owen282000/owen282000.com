Apps, die deine Daten auf deiner eigenen Hardware lassen

Ich bin Owen Vogelaar. Ich entwickle Open-Source-Apps, die deine Daten an einen Server senden, den du selbst betreibst. Eine Cloud von mir oder ein Konto gibt es dazwischen nicht.
